RTSP 摄像头 ESP32-CAM 摄像头 ONVIF 摄像头 的区别

  1. RTSP 摄像头： 能通过 RTSP 拉视频流的摄像头。视频流协议
    • 视频流协议
    • 用于实时传输视频
  2. ONVIF ：支持 ONVIF 监控标准的摄像头。设备管理协议
    • 监控行业统一标准
    • 用于设备发现、控制、配置
    • ONVIF 摄像头通常都支持 RTSP
  3. ESP32-CAM 摄像头:带摄像头的微控制器开发板。硬件设备

开启后将网关的Zigbee模块发射功率调至最大,用于增强Zigbee的信号强度

wifi 访问

通过 Wi-Fi 访问网关提示说明：
如果 Wi-Fi 和以太网分属不同子网，切换网络，可能会发生以下情况：

  1. 可能导致网关网页暂时断开连接，检查并确认网关连接的网络与电脑连接的网络在同一局域网下后，即可恢复连接；
  2. 可能导致通过 Add-on 同步至网关的设备暂时离线。但请放心，切换回原网络并重新检测设备状态后，设备将自动恢复上线，或将设备重新进行同步；
  3. 可能导致通过 IP 进行访问的 Add-on 无法进行访问，可使用切换的 Wi-Fi 网络对应的网卡 IP 重新进行访问；

    远程

    启用远程开关，为您生成远程访问 eWeLink CUBE 的链接，通过访问生成的链接来远程访问 eWeLink CUBE Cast 并接收推送通知
  • 通过远程连接， 可以访问cast 和 cube 跳过了登录
  • 推送操作设置 ：

备份恢复

  1. 创建备份： 备份网关数据，让您的数据不再丢失，您可以在网关升级前或做重要编辑/配置前创建备份文件，也可以设置固定时间自动备份

    • 点击下一步 ，提醒：
      • 最多支持存储4个手动备份文件，1个自动备份文件，存储空间不足将会自动覆盖最早的备份
      • 备份过程中系统将会冻结无法使用直至备份完成
      • 为了保证备份文件的完整，请备份过程中网关不要断电或重启
    • 手动备份
      • 备份名称
      • 密码
      • 确认密码


    • 自动备份
      • 自动备份时间： 默认4点，24小时内
      • 自动备份频率：
      • 启用/禁用开关
      • 提示：备份过程中系统将会冻结无法使用直至备份完成，请合理设置您的自动备份时间 自动备份文件仅存储一份，每次自动备份将会覆盖上一次的备份文件

  2. 恢复备份

    • 提醒： 不支持回退版本，在恢复前请将网关升级到最新版本
  • 恢复add-on数据前，请确保网关可访问互联网
  • 恢复过程中系统将会冻结无法使用直至恢复完成，为了保证备份文件的完整，请备份过程中网关不要断电或重启，恢复完成将会退出登录并重启网关
  • 新旧网关替换，如存在部分设备无法上线，请重新添加
  • 请在恢复完成后将旧网关恢复出厂设置
  • 3s倒计时
  • 因为存储空间有限，仅支持4个手动备份文件 1个自动备份文件
  • 本地文件恢复：上传本地文件
  • 选择一个版本恢复，需要输入密码

  1. Zigbee2CUBE 备份

    • Zigbee2CUBE 备份是为了将 eWeLink CUBE 的 Zigbee 数据备份为 Home Assistant 可用的格式，支持将下载的Zigbee2CUBE备份文件恢复到 Home Assistant 的 ZHA /Zigbee2MQTT 中，恢复教程>>

    • 下载的备份文件是为Home Assistant 特殊处理的，不可以恢复到 eWeLink CUBE 中

    • 相同的Zigbee网络不可同时在 eWeLink CUBE 和 ZHA /Zigbee2MQTT中使用

简而言之，ZigBee设备，尤其是NON-ZigBee3.0设备要与iHost门户网站兼容并正确显示，必须同时满足三个条件

  1. ZigBee 报告的型号符合 Zigbee2CUBE 支持的类型列表。
  2. ZigBee设备报告的功能（暴露）符合 Zigbee2CUBE 支持的类型和功能。
  3. eWeLinkCUBE 系统具有相应的用户界面能力，即可以正确显示设备，目前支持开关类、照明类和一些传感器类。
